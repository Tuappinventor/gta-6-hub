VICE HUB 3.1 - INSTALACIÓN SIN BORRAR DATOS

1. Ejecuta upgrade-v31.sql en Supabase SQL Editor. Es una migración aditiva.
2. Sube api/article.js, api/sitemap.js, vercel.json y portal-v31.js al repositorio,
   respetando las carpetas. No sustituyas scripts/publish-news.mjs ni otros archivos.
3. En index.html, justo DESPUÉS de <script src="./portal-v3.js"></script>,
   añade <script src="./portal-v31.js"></script>.
4. En Vercel, Project Settings > Environment Variables, configura:
   SUPABASE_URL = la URL pública de tu proyecto Supabase (igual que config.js)
   SUPABASE_ANON_KEY = la clave PUBLICABLE/anon de config.js
   No pongas SUPABASE_SERVICE_ROLE_KEY en la web ni en estos archivos.
   Vuelve a desplegar en Vercel tras guardar las variables.
5. Comprueba /articulo/slug-de-una-noticia y /sitemap.xml.
6. Mantén robots.txt con la URL del sitemap existente.

IMPORTANTE: este paquete implementa páginas HTML indexables y enlazado, pero NO
activa una nueva redacción automática ni descarga imágenes de terceros.
El pipeline actual de AutoNews se mantiene. La revisión de fuentes/imágenes
necesita un cambio adicional del pipeline y permisos de uso de las imágenes.

Si el proyecto de Vercel usa otro framework o una configuración de build especial,
revisa los rewrites antes de subirlos.
